# BIC502A — Introduction to Programming

## Unit II — Viewing File Contents

**M.Sc. in Computational Biology and Bioinformatics**  
**Course Code:** BIC502A  
**Unit:** II  
**Duration:** 8 hours

## Syllabus

**Viewing file contents:** Using text editors: `vim`, `nano`, `gedit`; Using shell: `cat`, `less`, `more`, `head`, `tail`, `fold`; Searching for contents: `grep`, `egrep`; Data manipulation: `cut`, `paste`, `sed`, `awk`; piping and writing files using Bash.

## Unit II Topics

- Text editors: `vim`, `nano`, `gedit`
- Shell commands: `cat`, `less`, `more`, `head`, `tail`, `fold`
- Searching for contents: `grep`, `egrep`
- Data manipulation: `cut`, `paste`, `sed`, `awk`
- Piping
- Writing files using Bash

## Practical Material

This repository contains practical material corresponding to the Unit II syllabus, including exercises and supporting files for working with file contents, searching, data manipulation, piping, and Bash.
